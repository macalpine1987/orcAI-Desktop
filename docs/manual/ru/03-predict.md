# Распознавание

Модель ищет в записях акустические сигналы косаток: свисты, серии эхолокационных щелчков, дискретные крики и другие классы. Результат для каждой записи сохраняется в текстовый файл рядом с ней.

Распознавание выполняется в три этапа, каждому соответствует своя вкладка: **Параметры** (запуск), **Анализ** (просмотр найденных сигналов), **Фильтрация** (исключение сигналов неподходящей длительности).

Если классы или параметры спектрограммы выбранной модели не совпадают с параметрами проекта, приложение выводит предупреждение. Распознавание при этом можно запустить, но кнопка **Тест** в разделе **Модели** для такой пары недоступна.

## Параметры {#parameters}

На вкладке выбираются записи и настройки распознавания.

| Параметр | Описание |
|----------|----------|
| **Модель** | Модель, с помощью которой выполняется распознавание. Для начала работы подходит встроенная `orcai-isl-v1` |
| **Канал** | Номер анализируемого канала для многоканальных записей. По умолчанию 1 |
| **Порог** | Минимальная вероятность, при которой сигнал попадает в файл меток. Чем выше порог, тем меньше ложных срабатываний, но тем выше риск пропустить слабые сигналы. По умолчанию 0,50 |
| **Файлы для распознавания** | Список всех WAV-файлов проекта. Обрабатываются только отмеченные файлы |
| **Перезаписать существующий результат** | Заменяет ранее созданные файлы результатов |
| **Сохранить вероятности** | Сохраняет вероятность каждого найденного сигнала |
| **Дополнительно** | Путь для файлов меток, суффикс меток и уровень детализации журнала |

Чтобы запустить распознавание, выберите файлы и нажмите **Запустить распознавание**.

### Суффикс меток

По умолчанию используется суффикс `*`: в файле меток класс записывается как `WHISTLE*`. Если поле суффикса пустое, суффикс не добавляется. Столбец **Тип** на вкладке **Анализ** суффикс не показывает; при экспорте в Audacity подпись берётся из файла.

### Команда и время обработки

В нижней части экрана отображается команда orcAI, которая будет выполнена. Её можно скопировать. Рядом указано ориентировочное время обработки; фактическое время может отличаться от оценки примерно в 1,5 раза в обе стороны. Если файлы не выбраны, вместо времени отображается прочерк.

### Пресеты

Сочетания настроек хранятся в списке **Пресет проекта**. Кнопки **Сохранить** и **Сохранить как…** расположены рядом с вкладками:

- **Сохранить** обновляет выбранный пресет. Общий пресет при этом не привязывается к открытому проекту;
- **Сохранить как…** создаёт новый пресет для открытого проекта.

### Результаты

Результаты сохраняются в файлы `*_predicted.txt`. Эти файлы можно открыть в Audacity как дорожку меток.

## Анализ {#results}

На вкладке **Анализ** отображаются найденные моделью сигналы. Спектрограмма строится так же, как в orcAI (режим `display_kind=orcai`, диапазон частот 0–16 кГц), поэтому изображение соответствует иллюстрациям в публикациях.

> **Примечание.** Цветные полосы на спектрограмме — это метки класса по **времени** (как дорожки в Audacity), а не по частоте. По вертикали на спектрограмме — частота (0–16 кГц), поэтому полоса может лежать не там, где видна энергия сигнала. В файлах orcAI (`*_predicted.txt`, аннотации) есть только начало, конец и класс, без частотных границ.

Элементы вкладки:

| Элемент | Назначение |
|---------|------------|
| Панель воспроизведения | Воспроизведение записи, прозрачность меток, масштаб по времени |
| Спектрограмма | Найденные сигналы отмечены цветными полосами по классам (по времени, не по частоте); каждому классу соответствует свой цвет |
| Рейка **Классы** (справа) | Скрытие отдельных классов и выбор минимальной вероятности для отображения |
| Таблица сигналов (внизу) | Время начала и окончания, длительность, класс (код, например `WHISTLE`), тип (читаемое имя, часто взятое из синонима метки) и вероятность. Щелчок по строке перемещает спектрограмму к соответствующему сигналу |

Все переключатели влияют только на отображение; файлы результатов не изменяются. Показ спектрограммы и режим для длинных записей настраиваются в **Настройки → Среда выполнения** (**Показывать спектрограмму**, **Длинные записи**).

> **Примечание.** Не путайте вкладку **Анализ** с разделом **Результаты** в боковом меню: в разделе **Результаты** собраны сводные данные по всем записям проекта.

## Фильтрация {#filter}

Модель может отметить слишком короткие или слишком длинные сигналы. На вкладке **Фильтрация** для каждого класса задаётся допустимый диапазон длительности; сигналы вне диапазона исключаются. Фильтрацию выполняет команда orcAI `filter-predictions`.

### Порядок работы

1. Выберите класс. Гистограмма показывает распределение длительности найденных сигналов этого класса.
2. Задайте минимум и максимум: введите значения или выделите диапазон на гистограмме. Пустой минимум принимается равным 0, пустой максимум означает отсутствие верхней границы.
3. Проверьте предварительный результат: сколько сигналов останется и сколько будет исключено.
4. Нажмите **Применить фильтр**.

Исходный файл `*_predicted.txt` не изменяется. Отфильтрованный результат записывается в отдельный файл `*_predicted_filtered.txt`.

### Таблица пределов длительности

Первая строка таблицы — **default**. Её пределы применяются к классам, для которых в таблице нет отдельной строки. Если строка с именем класса есть, orcAI использует именно её пределы, даже если минимум равен 0, а максимум не задан. Классы, отсутствующие в выбранном файле результатов, в таблицу не включаются.

Гистограмма отображается в двух случаях:

- без отдельной строки остался один класс: гистограмма показывает его сигналы;
- без отдельной строки осталось несколько классов: общий график не строится. Выберите нужный класс щелчком по строке таблицы, включая строку **default**.

### Значения по умолчанию и пример

По умолчанию для всех классов задан минимум 0 и верхняя граница отсутствует, поэтому orcAI ничего не исключает. Задайте собственные пределы или нажмите **Пример**: будут подставлены минимальные значения из публикации, верхняя граница останется открытой. Классы, для которых в примере значения не заданы, обрабатываются по строке **default**.

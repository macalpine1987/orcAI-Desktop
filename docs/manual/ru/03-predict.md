# Распознавание

В этом разделе модель ищет в записях звуки косаток: свисты, серии эхолокационных щелчков, дискретные крики и другие классы. Результат для каждой записи сохраняется в текстовый файл рядом с ней.

Раздел состоит из трёх вкладок, которые обычно проходят по порядку: **Параметры** → **Анализ** → **Фильтрация**.

Если классы или параметры спектрограммы выбранной модели не совпадают с проектом, программа покажет предупреждение. Распознавание при этом можно запустить. Кнопка **Тест** в разделе **Модели** для такой пары недоступна.

## Параметры {#parameters}

Здесь выбираются записи и настройки распознавания.

- **Модель** — какой нейросетью распознавать. Для начала подойдёт встроенная `orcai-isl-v1`.
- **Канал** — для многоканальных записей укажите, какой канал анализировать.
- **Порог** — минимальная вероятность, при которой сигнал попадает в файл меток. Чем выше порог, тем меньше ложных срабатываний и тем больше можно пропустить слабых сигналов. Если не уверены, оставьте значение по умолчанию.
- **Файлы для распознавания** — все WAV проекта. Запускаются только отмеченные.
- **Перезаписать существующий результат** и **Сохранить вероятности** — на той же панели.
- **Дополнительно** — путь вывода меток, суффикс меток и детализация лога. По умолчанию суффикс `*`: в файле меток класс записывается как `WHISTLE*`. Пустое поле суффикс не добавляет. Столбец **Тип** на вкладке **Анализ** его не показывает; экспорт в Audacity берёт подпись из файла.

Внизу экрана показана команда orcAI, которая будет выполнена, — её можно скопировать. Там же приводится примерное время обработки. Это ориентир: реальное время может отличаться примерно в полтора раза в обе стороны. Если файлы не выбраны, вместо времени стоит прочерк.

Сочетания настроек хранятся в списке **Пресет проекта**. Кнопки **Сохранить** и **Сохранить как…** стоят рядом с вкладками. **Сохранить** обновляет выбранный пресет и не привязывает общий пресет к открытому проекту. **Сохранить как…** создаёт пресет для открытого проекта.

Результаты сохраняются в файлы `*_predicted.txt`. Их можно открыть в Audacity как дорожку меток.

## Анализ {#results}

На вкладке **Анализ** можно подробно рассмотреть, что нашла модель. Спектрограмма строится тем же способом, что и в orcAI (режим `display_kind=orcai`, частоты 0–16 кГц), поэтому картинка совпадает с иллюстрациями из публикаций.

На экране:

- **панель воспроизведения** — проигрывание записи, прозрачность меток и масштаб по времени;
- **спектрограмма** — найденные сигналы отмечены цветными полосами, у каждого класса свой цвет;
- рейка **Классы** справа — можно скрыть отдельные классы и задать минимальную вероятность для показа;
- **таблица сигналов** внизу — время начала и конца, длительность, класс, тип звука и вероятность. Щелчок по строке переносит к этому месту на спектрограмме.

Все переключатели меняют только отображение — файлы с результатами остаются прежними.

Не путайте эту вкладку с разделом **Результаты** в боковом меню: там собрана сводка сразу по всем записям проекта.

## Фильтрация {#filter}

Модель иногда отмечает слишком короткие или слишком длинные сигналы. На вкладке **Фильтрация** для каждого класса задаётся допустимая длительность, и всё, что в неё не укладывается, отбрасывается. Это делает команда orcAI `filter-predictions`.

Как пользоваться:

1. Выберите класс. Гистограмма покажет, какой длительности сигналы этого класса нашла модель.
2. Задайте минимум и максимум — введите числа или выделите нужный диапазон прямо на гистограмме. Пустой минимум считается нулём, пустой максимум — без верхней границы.
3. Посмотрите предпросмотр: сколько сигналов останется, а сколько будет отброшено.
4. Нажмите **Применить фильтр**.

В таблице пределов длительности первая строка — **default**. orcAI применяет её к классам, у которых нет своей строки. Если у класса заданы свои пределы, берётся его строка, даже когда минимум равен 0, а максимум пуст. При выборе **default** гистограмма показывает длительности сигналов всех классов.

Исходный файл `*_predicted.txt` не меняется. Отфильтрованный результат записывается в отдельный файл `*_predicted_filtered.txt`, так что к исходным данным всегда можно вернуться.

Набор по умолчанию для всех классов — минимум 0 и без максимума, поэтому orcAI ничего не отбрасывает. Задайте свои пределы или нажмите **Пример orcai-v1**: подставятся минимумы из публикации, верхняя граница останется открытой. Классы, для которых пример ничего не задаёт, проходят по строке **default**.

# Проекты

Проект — папка на диске, в которой хранятся все материалы одного исследования: аудиозаписи, разметка, результаты распознавания, промежуточные файлы обучения и обученные модели. Структура папки совпадает со структурой проектов orcAI, созданных в командной строке, поэтому один и тот же проект можно открывать и в приложении, и в терминале.

Для работы с проектами на странице **Главная** должна быть запущена среда выполнения.

Пока проект не создан или не выбран активным, пункты меню **Распознавание**, **Обучение**, **Модели**, **Результаты** и **Задачи** отображаются, но недоступны. Разделы **Главная**, **Проекты**, **Настройки** и **Справка** доступны всегда.

## Открытие проекта и добавление файлов

Три действия не взаимозаменяемы:

1. **Список проектов** — открыть проект или переключиться на другой из списка проектов, известных приложению.
2. **Открыть папку проекта** у активного проекта — показать его папку в файловом менеджере (на macOS — Finder, на Windows — Проводник). Другую папку кнопка не подключает.
3. **Открыть папку проекта** в пустом состоянии раздела **Проекты** (проект не выбран) — указать существующую папку orcAI на диске, в том числе созданную в терминале, чтобы добавить её в список приложения. Здесь та же подпись означает подключение папки, а не показ в файловом менеджере. Преобразование не требуется.

Чтобы начать новый проект, нажмите **Создать проект**. Не создавайте новый проект с тем же именем поверх существующей папки: подключите саму папку (действие 3).

- Чтобы добавить записи, нажмите **Добавить WAV** на вкладке **Записи** или перетащите WAV-файлы в область «Перетащите WAV-файлы сюда».
- Чтобы добавить аннотации, нажмите **Добавить аннотации** на вкладке **Аннотации** или перетащите файлы `.txt` в область «Перетащите .txt сюда или нажмите „Добавить аннотации“».

## Создание проекта

1. Нажмите **Создать проект**.
2. Укажите название проекта и папку.
3. Выберите цель проекта (см. раздел «Цель проекта»).

Приложение создаст структуру папки и файл параметров. Это равнозначно команде `orcai init`. После создания проекта добавьте записи.

## Вкладки проекта

| Вкладка | Назначение |
|---------|------------|
| **Записи** | Список WAV-файлов проекта. Здесь же добавляются новые записи. Принимаются файлы PCM с разрядностью 16–32 бит; частота дискретизации берётся из заголовка файла. Таблицу `recording_table.csv`, по которой orcAI определяет обрабатываемые файлы, приложение ведёт автоматически |
| **Аннотации** | Файлы разметки, в которых вручную отмечено, где и какой звук слышен. Формат — текстовые метки Audacity (`.txt`). Аннотации необходимы для обучения моделей и не требуются для распознавания. Пока в проекте нет ни одного файла аннотаций, кнопка **Мастер обучения** на этой вкладке недоступна |
| **Артефакты** | Файлы, создаваемые шагами обработки: спектрограммы, наборы данных для обучения, результаты распознавания. Здесь можно увидеть, что уже готово, и удалить лишние файлы, чтобы освободить место |
| **Параметры** | Параметры проекта, используемые orcAI и мастером обучения |

## Цель проекта {#focus}

При создании проекта задаётся цель, от которой зависят подсказки и доступность раздела **Обучение**:

| Цель | Раздел «Обучение» |
|------|-------------------|
| Распознавание | Пункт меню отображается, но недоступен. Остальные разделы работают в обычном режиме |
| Обучение модели | Доступен |
| Полный цикл | Доступен |

Цель проекта можно изменить в любой момент переключателями цели в шапке карточки проекта.

## Готовность проекта {#readiness}

Панель готовности анализирует содержимое папки проекта и предлагает следующий шаг, например «Добавьте аннотации» или «Можно запускать обучение». Подсказки панели носят рекомендательный характер.

Исключение составляют операции, которым необходима разметка: мастер обучения и шаги конвейера не запускаются, пока в проекте нет хотя бы одной аннотации (см. главу «Обучение»).

После добавления записей приложение не переключает вкладку автоматически: вкладка **Аннотации** и пункт в блоке **Следующий шаг** подсвечиваются.

## Таблица записей и классы звуков

Таблица `recording_table.csv` содержит пути к записям и аннотациям, а также по одной колонке для каждого класса звуков (`WHISTLE`, `BUZZ` и другие). Значение в колонке указывает, присутствует ли класс в записи. Без этих колонок orcAI не может построить массивы меток на следующем шаге обучения.

> **Важно.** При создании и обновлении таблицы приложение по умолчанию отмечает для каждой записи, у которой есть аннотация, все классы как присутствующие. Команда `orcai create-recording-table` в терминале заполняет эти колонки иначе. Если в некоторых записях отдельных классов заведомо нет, исправьте таблицу вручную.

### Обновление таблицы

При ручном обновлении таблицы в диалоге можно задать:

| Параметр | Флаг orcAI | Назначение |
|----------|------------|------------|
| Канал по умолчанию | `-dc` | Канал, используемый для многоканальных записей |
| Удаление дубликатов имён | `-rdf` | Исключает повторяющиеся имена файлов |
| Путь исключений | `-ep` | Файлы, которые не включаются в таблицу |

Автоматическая синхронизация после добавления или удаления WAV-файлов выполняется с параметром `-dc 1` и без `-rdf` и `-ep`. Обновление из раздела **Проекты** выполняется с параметрами `-ut` (`update_table`: дописать существующую таблицу) и `-up` (`update_paths`: обновить пути к файлам). Эти режимы не обязательно пересобирают таблицу с нуля: полная пересборка выполняется в режиме перезаписи.

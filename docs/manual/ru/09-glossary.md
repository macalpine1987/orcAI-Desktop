# Глоссарий

## Термины

| Термин | Определение |
|--------|-------------|
| Аннотация | Ручная разметка записи: где и какой звук слышен. Хранится в текстовом файле меток Audacity |
| Батч | Группа обучающих примеров, обрабатываемая моделью за один шаг |
| Выборки train / val / test (TVT) | Три части набора данных: обучающая (train), проверочная (val — контроль в ходе обучения) и тестовая (test — итоговая оценка) |
| Гиперпараметры | Настройки архитектуры нейронной сети: число фильтров, размер ядра, dropout и другие |
| Дообучение | Продолжение обучения готовой модели на новых данных |
| Класс | Код звука в параметрах модели и файлах меток, например `WHISTLE`. Не следует путать с типом |
| Конвейер | Последовательность из восьми шагов, через которые проходят данные при обучении |
| Порог | Минимальная вероятность, при которой сигнал попадает в файл меток |
| Синонимы меток | Соответствие между подписями в аннотациях (`.txt`) и классами модели. Хранится в файле `call_equivalences.json` |
| Сниппет | Фрагмент спектрограммы фиксированной длительности; один обучающий пример |
| Спектрограмма | Изображение звука: по горизонтали — время, по вертикали — частота, яркость соответствует громкости |
| Тип | Читаемое имя сигнала в таблице обнаружений (часто берётся из синонима метки). Не следует путать с классом |
| Шаг окна (`n_overlap`) | На сколько отсчётов сдвигается окно БПФ. Имя в файле параметров — `n_overlap`; по смыслу это hop (шаг), а не доля перекрытия. Может быть больше размера окна (`nfft`) |
| Эпоха | Один полный цикл обучения модели |
| `val_MBA` | Доля верных ответов на проверочной выборке. Классы без разметки в записи не учитываются. По этой метрике следят за прогрессом и сохраняют лучшую модель |

## Разделы приложения и команды orcAI

| Раздел приложения | Команда orcAI | Файлы |
|-------------------|---------------|-------|
| Распознавание | `predict` | `*_predicted.txt` |
| Фильтрация | `filter-predictions` | `*_predicted_filtered.txt`, `*_call_duration_limits.json` |
| Обучение | `train` и подготовительные шаги | `models/<имя>/` |
| Дообучение | `train` с исходной моделью | `models/<имя>/` |
| Тест модели | `test` | Результаты теста в папке модели |
| Создание проекта | `init` | `*_orcai_parameter.json` |
| Таблица записей | `create-recording-table` | `recording_table.csv` |
| Синонимы меток | Используются шагом `create-label-arrays` | `call_equivalences.json` |

## Классы звуков

Названия классов не переводятся, чтобы их можно было сопоставить с публикациями. В таблицах приложения рядом с классом указан тип — читаемая подпись.

| Класс | Тип в приложении | Звук |
|-------|------------------|------|
| `WHISTLE` | whistles | Свисты |
| `BUZZ` | buzzing | Серии эхолокационных щелчков |
| `PHS` | prey handling sounds | Звуки поедания добычи |
| `SS` | pulsed calls | Дискретные крики |
| `BR` | breathing | Дыхание при всплытии |
| `HERDING` | herding calls | Низкочастотный крик перед ударом по косяку |
| `TAILSLAP` | tail slaps | Подводные удары хвостом |

Точный набор классов зависит от модели. Его можно посмотреть в описании модели в разделе **Модели**.

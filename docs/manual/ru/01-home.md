# Главная

Страница **Главная** — стартовый экран приложения. На ней запускается среда выполнения, отображается состояние текущего проекта и расположены ссылки на основные операции.

## Среда выполнения

Для распознавания записей и обучения моделей необходимы два компонента:

- **Sidecar (API)** — служебный процесс, через который интерфейс передаёт команды orcAI. Работает только на вашем компьютере и не обращается к сети Интернет.
- **Движок orcAI** — процесс, в котором orcAI выполняет вычисления на центральном процессоре (CPU) или графическом процессоре (GPU).

Кнопки блока «Среда выполнения»:

| Кнопка | Действие |
|--------|----------|
| **Запуск** | Запускает оба компонента |
| **Перезапустить** | Останавливает и снова запускает оба компонента. Используйте, если среда перестала отвечать |
| **Остановить** | Останавливает вычисления и снимает с очереди незавершённые задачи. Завершённые задачи остаются в списке. Окно приложения не закрывается |

Зелёные индикаторы означают, что среда готова к работе.

> **Примечание (оболочка).** На macOS закрытие окна кнопкой или ⌘W только скрывает его: вычисления продолжаются в фоне; полный выход — ⌘Q. На Windows сверните окно, чтобы оставить вычисления в фоне; закрытие окна (✕ или Alt+F4) завершает приложение и останавливает среду.

Устройство для вычислений (CPU или GPU) выбирается в **Настройки → Среда выполнения**. После смены устройства движок перезапускается автоматически.

## Текущий проект

Карточка текущего проекта содержит:

- число записей и аннотаций;
- число записей, для которых получены результаты распознавания;
- выбранную модель.

Кнопка **Открыть папку** открывает папку проекта в файловом менеджере (на macOS — Finder, на Windows — Проводник). Кнопка **Перейти** открывает раздел **Проекты**; файлы проекта при этом не изменяются.

## Быстрые действия и последние задачи

Четыре карточки быстрых действий ведут к операциям с текущим проектом:

- **Распознать записи**;
- **Обучить модель**;
- **Отфильтровать**;
- **Посмотреть результаты**.

Если проект не выбран, карточки недоступны. Ниже карточек отображаются последние задачи. Полный список находится в разделе **Задачи**, который также доступен только при выбранном проекте.

## Подсказки

Приложение может выводить подсказки в шапке окна, если данные проекта неполны или устарели:

- недостаточно записей или аннотаций;
- таблица записей устарела;
- для обучения не хватает сниппетов.

Подсказки носят информационный характер и не ограничивают работу. По умолчанию они выключены; включить их можно в **Настройки → Интерфейс → Отображать советы**.

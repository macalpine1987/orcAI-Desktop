# Настройки

Настройки разделены на две вкладки: **Среда выполнения** и **Интерфейс**. Сведения о версии программы находятся в разделе **Справка → О программе**.

## Среда выполнения

- **Запускать движок при старте** — включать среду выполнения сразу при открытии программы, без кнопки **Запуск** на Главной. По умолчанию выключен.
- **Показывать спектрограмму** — если выключить, на вкладке **Анализ** вместо графика остаётся таблица обнаружений на всю высоту, без панели воспроизведения. Фильтр классов по-прежнему открывается кнопкой **Классы**.
- **Длинные записи** — для записей длиннее 20 минут спектрограмма строится только на видимом участке. Результаты распознавания от этого не меняются. Переключатель доступен, только когда спектрограмма включена.
- **Устройство для нейросети** — процессор (CPU) или видеокарта (GPU). При первом запуске выбран CPU. После смены среда перезапускается сама.

Блок **Данные**:

- **Каталог проектов** — папка, которую мастер создания предлагает по умолчанию. Если она не задана, берётся домашняя папка.
- **Данные приложения** и **Журнал sidecar** — служебные файлы программы.
- **Кэш спектрограмм** — тайлы спектрограммы. Кнопка **Очистить** их удаляет; записи и проекты не затрагиваются.
- **Сброс приложения** — удаляет историю задач, список проектов в программе, кэши, файл настроек и журнал sidecar. Папки записей на диске, включая обученные модели внутри них, не удаляются. После сброса проект нужно снова открыть из папки.

## Интерфейс

- **Язык** — русский или английский. По умолчанию английский. Справка переключается вместе с интерфейсом.
- **Предупреждения о данных** — подсказки в верхней части окна, если в проекте не хватает записей или аннотаций, устарела таблица записей или для обучения недостаточно сниппетов. По умолчанию выключены.
- **Масштаб интерфейса** — 100 % или 125 %.
- **Полноэкранный режим** — открывать программу во весь экран. Переключить режим в любой момент можно клавишей F11.
- **Консоль по умолчанию** — **Свёрнута** или **Развёрнута**. Тот же выбор сохраняет переключатель в самой консоли.

Справа показан мини-макет: как выбранный масштаб выглядит на экране «Задачи».

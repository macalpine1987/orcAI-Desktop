# Настройки

Настройки разделены на две вкладки: **Среда выполнения** и **Интерфейс**. Версия приложения указана в разделе **Справка → О программе**.

## Среда выполнения

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| **Запускать движок при старте** | Запускает среду выполнения при открытии приложения, без нажатия кнопки **Запуск** на странице **Главная** | Выключен |
| **Показывать спектрограмму** | Если параметр выключен, на вкладке **Анализ** вместо спектрограммы отображается таблица обнаружений на всю высоту, без панели воспроизведения. Фильтр классов по-прежнему открывается кнопкой **Классы** | Включён |
| **Длинные записи** | Для записей длительностью более 20 минут спектрограмма строится только для видимого участка. На результаты распознавания параметр не влияет. Доступен только при включённом параметре **Показывать спектрограмму** | Выключен |
| **Устройство для нейросети** | Устройство вычислений: центральный процессор (CPU) или видеокарта (GPU). После смены устройства среда перезапускается автоматически | CPU |

> **Примечание.** Параметры **Показывать спектрограмму** и **Длинные записи** находятся на вкладке **Среда выполнения** (не **Интерфейс**), хотя влияют на отображение вкладки **Анализ**.

### Данные

| Параметр | Описание |
|----------|----------|
| **Каталог проектов** | Папка, предлагаемая по умолчанию при создании проекта. Если не задана, используется домашняя папка пользователя |
| **Данные приложения**, **Журнал sidecar** | Служебные файлы приложения |
| **Кэш спектрограмм** | Сохранённые фрагменты изображений спектрограмм. Кнопка **Очистить** удаляет кэш; записи и проекты не затрагиваются |
| **Сброс приложения** | Удаляет историю задач, список проектов в приложении, кэши, файл настроек и журнал Sidecar. Папки проектов на диске, включая записи и обученные модели, не удаляются. После сброса откройте проект заново из его папки |

> **Важно.** Операция «Сброс приложения» необратима для перечисленных данных. Перед сбросом убедитесь, что история задач вам не нужна.

## Интерфейс

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| **Язык** | Русский или английский. Язык справки переключается вместе с языком интерфейса | Английский |
| **Отображать советы** | Подсказки в шапке окна: не хватает записей или аннотаций, устарела таблица записей, недостаточно сниппетов для обучения | Выключен |
| **Масштаб интерфейса** | 100 % или 125 % | 100 % |
| **Полноэкранный режим** | Открытие приложения на весь экран. Режим можно переключить в любой момент горячей клавишей F11 | Выключен |
| **Консоль по умолчанию** | Состояние консоли при открытии: **Свёрнута** или **Развёрнута**. Тот же выбор сохраняется при переключении в самой консоли | Свёрнута |

Справа отображается мини-макет: как выбранный масштаб выглядит на экране «Задачи».

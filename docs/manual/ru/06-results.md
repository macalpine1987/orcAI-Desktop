# Результаты

Раздел **Результаты** объединяет в одной таблице сигналы из всех записей проекта. В нём можно искать по проекту и выгружать данные для анализа в других программах.

Для просмотра сигналов отдельной записи на спектрограмме используйте вкладку **Распознавание → Анализ**.

## Источники данных

В верхней части раздела выбирается источник данных:

| Источник | Файлы |
|----------|-------|
| **Распознанные** | Результаты распознавания (`*_predicted.txt`) |
| **После фильтра** | Результаты после фильтрации по длительности (`*_predicted_filtered.txt`) |
| **Аннотации** | Ручная разметка (`annotations/*.txt`). Позволяет сравнить разметку с результатами модели |

Приложение только читает эти файлы и не изменяет их.

## Сводные показатели

Над таблицей отображаются:

- число найденных сигналов и число файлов, в которых они найдены;
- суммарная длительность сигналов;
- средняя вероятность;
- порог, с которым выполнялось распознавание.

Если файл не удалось прочитать, приложение выводит сообщение об этом.

## Таблица

Таблицу можно отфильтровать по файлу, классу и минимальной вероятности, а также найти запись по имени. Фильтр по вероятности не применяется к аннотациям, так как у ручной разметки вероятности нет.

Щелчок по строке или кнопка **Открыть** переходит на вкладку **Распознавание → Анализ** к выбранному сигналу на спектрограмме.

## Выгрузка

| Действие | Результат |
|----------|-----------|
| **Экспорт CSV** | Сохраняет видимые строки таблицы в CSV-файл для Excel, R или Python |
| **Экспорт в Audacity** | Сохраняет видимые строки в виде дорожек меток Audacity, отдельно для каждой записи |

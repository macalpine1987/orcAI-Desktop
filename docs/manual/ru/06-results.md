# Результаты

Раздел собирает в одну таблицу все сигналы, найденные во всех записях проекта. Здесь ищут сигналы по всему проекту и выгружают их для дальнейшего анализа.

## Источники данных

Вверху выбирается, что показывать:

- **Распознанные** — результаты распознавания (файлы `*_predicted.txt`);
- **После фильтра** — результаты после фильтрации по длительности (`*_predicted_filtered.txt`);
- **Аннотации** — ручная разметка (`annotations/*.txt`). Её можно сравнить с тем, что нашла модель.

Программа только читает эти файлы и ничего в них не меняет.

## Сводные показатели

Над таблицей показаны итоги: сколько сигналов найдено и в скольких файлах, их общая длительность, средняя вероятность и порог, с которым проводилось распознавание. Если какой-то файл не удалось прочитать, программа об этом сообщит.

## Таблица

Таблицу можно отфильтровать по файлу, классу и минимальной вероятности, а также найти запись по имени. Фильтр по вероятности не действует на аннотации: у ручной разметки её нет.

Щелчок по строке или кнопка **Открыть** переносит на вкладку **Распознавание → Анализ**, прямо к этому сигналу на спектрограмме.

## Выгрузка

- **Экспорт CSV** — сохраняет строки, которые сейчас видны в таблице, в файл для Excel, R или Python.
- **Экспорт в Audacity** — сохраняет видимые строки как дорожки меток Audacity, отдельно для каждой записи.

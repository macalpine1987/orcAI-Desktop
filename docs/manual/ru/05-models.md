# Модели

В разделе **Модели** собраны все модели, доступные в проекте: встроенные и обученные пользователем.

## Встроенные модели

| Модель | Описание |
|--------|----------|
| `orcai-isl-v1` | Основная модель, обученная на большом наборе записей исландских косаток, охотящихся на сельдь. Применяется без изменений или дообучается на данных другой популяции |
| `orcai-nor-v1` | Модель `orcai-isl-v1`, дообученная на записях норвежских косаток |

Модели, обученные пользователем, хранятся в папке проекта `models/`, каждая в отдельной подпапке.

## Действия с моделью

При выборе модели в таблице справа отображается её описание: классы звуков, параметры спектрограммы и результаты теста (если он выполнялся).

| Действие | Описание |
|----------|----------|
| **Использовать** | Назначает модель для распознавания и открывает вкладку **Параметры** |
| **Дообучить** | Открывает мастер обучения, в котором выбранная модель используется как основа. Доступно при цели проекта «Обучение модели» или «Полный цикл» и наличии в проекте хотя бы одной аннотации |
| **Тест** | Измеряет качество модели на тестовой выборке проекта. Требует готовых TVT-датасетов. Недоступно, если параметры проекта не совпадают с параметрами модели |
| **Импорт** | Добавляет в проект модель из другой папки, например полученную от коллег |
| **Экспорт** | Копирует обученную модель проекта в другую папку. Встроенные модели входят в состав приложения и не экспортируются |
| **Открыть папку** | Открывает папку с файлами модели проекта. Папка встроенной модели не открывается |

## Результаты теста

По итогам теста для каждого класса отображаются два показателя:

- **Точность** (precision) — доля найденных моделью сигналов, которые действительно относятся к этому классу. Низкая точность означает большое число ложных срабатываний.
- **Полнота** (recall) — доля реальных сигналов класса, найденных моделью. Низкая полнота означает, что модель пропускает много сигналов.

## Совместимость

Модель рассчитана на классы и параметры спектрограммы, использованные при её обучении. При несовпадении с параметрами проекта приложение выводит предупреждение. Такую модель можно назначить для распознавания; недоступен только **Тест**, поскольку он использует параметры проекта.

# Задачи

Каждое действие, которое требует вычислений — распознавание, фильтрация, шаги обучения, тест модели, — становится задачей. Задачи выполняются по очереди, одна за другой, и все они собраны в этом разделе.

В колонке «Команда» указано имя команды orcAI (`predict`, `train` и так далее). Так их проще сопоставить с документацией orcAI.

## Состояния задач

- **В очереди** — задача ждёт, пока завершатся предыдущие.
- **Выполняется** — задача работает; видно, сколько процентов готово.
- **Готово** — задача завершилась успешно.
- **Ошибка** — задача завершилась неудачно. Причину смотрите в журнале.
- **Отменено** — задачу остановили вручную.

## Консоль

Консоль в нижней части окна показывает подробности о выбранной задаче. У неё четыре вкладки:

- **Лог** — всё, что orcAI сообщал во время работы;
- **Инспектор** — параметры, с которыми была запущена задача;
- **Ошибки** — только сообщения об ошибках;
- **Команда** — точная команда orcAI, которую можно повторить в терминале.

Консоль можно свернуть, чтобы она не занимала место.

## Управление задачами

- **Отменить** — прервать выполняющуюся задачу. Если она входит в план обучения, вместе с ней снимаются и следующие шаги этого плана.
- **Удалить** — убрать из очереди задачу, которая ещё не началась. Для шага плана это тоже отменяет следующие шаги.
- **Повторить** — запустить ещё раз задачу, которая завершилась с ошибкой.
- **Открыть** — показать файл результата завершённой задачи.
- **Экспорт лога** — сохранить журнал выбранной задачи.
- **Очистить** — удалить историю задач. Выполняющиеся задачи при этом отменяются.

Завершённые задачи сохраняются между запусками программы. Незавершённые снимаются, когда вы выходите из программы или нажимаете **Остановить** на Главной. Если свернуть окно на macOS, очередь продолжает работать.

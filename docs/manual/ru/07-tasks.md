# Задачи

Распознавание, фильтрация, шаги обучения и тестирование модели выполняются как задачи: по одной, в порядке очереди. В разделе **Задачи** отображаются задачи активного проекта.

В колонке «Команда» указано имя команды orcAI (`predict`, `train` и другие), так задачу проще сопоставить с документацией orcAI.

## Состояния задач

| Состояние | Значение |
|-----------|----------|
| В очереди | Задача ожидает завершения предыдущих |
| Выполняется | Задача выполняется; отображается процент готовности |
| Готово | Задача завершена успешно |
| Ошибка | Задача завершена с ошибкой; причина указана в журнале |
| Отменено | Задача остановлена вручную |

## Консоль

В нижней части окна расположена консоль с подробными сведениями о выбранной задаче. Она содержит четыре вкладки:

| Вкладка | Содержимое |
|---------|------------|
| **Лог** | Все сообщения orcAI, полученные во время выполнения |
| **Инспектор** | Параметры, с которыми была запущена задача |
| **Ошибки** | Только сообщения об ошибках |
| **Команда** | Точная команда orcAI, которую можно повторить в терминале |

Консоль можно свернуть, чтобы освободить место на экране.

## Управление задачами

| Действие | Описание |
|----------|----------|
| **Отменить** | Прерывает выполняющуюся задачу. Если задача входит в план обучения, следующие шаги плана также снимаются |
| **Удалить** | Удаляет из очереди задачу, которая ещё не началась. Для шага плана следующие шаги также снимаются |
| **Повторить** | Запускает повторно задачу, завершившуюся с ошибкой |
| **Открыть** | Открывает файл результата завершённой задачи |
| **Экспорт лога** | Сохраняет журнал выбранной задачи |
| **Очистить** | Удаляет историю задач. Выполняющиеся задачи при этом отменяются |

Завершённые задачи сохраняются между запусками приложения. Незавершённые задачи снимаются при выходе из приложения или при нажатии кнопки **Остановить** на странице **Главная**. При сворачивании окна (на macOS также при скрытии через ⌘W) очередь продолжает выполняться; на Windows для фона сверните окно — ✕ / Alt+F4 завершают приложение и снимают незавершённые задачи.

# Баг-репорт: объединение «Спектрограмма» → «Распознавание»

**Дата:** 2026-05-21  
**Роль:** Senior QA  
**Сборка:** ветка с `PredictPage` + `predictQueue` (UI, без полного E2E .app)

---

## Резюме

| Severity | Кол-во |
|----------|--------|

Основной сценарий (выбор WAV в проекте → очередь → спектрограмма → пакетный predict) реализован, но есть регрессии и незавершённые части.

---

## High

### BUG-PRED-001 — Регрессия: распознавание по `recording_table.csv` из проекта

**Шаги:** В проекте есть `recording_table.csv` → раньше кнопка вела на predict с CSV.

**Факт (исторический):** Кнопка «Распознавание аудиофайлов» работала только с **отмеченными WAV**; CSV-batch был убран.

**Исправление (2026-09):** при наличии `recording_table.csv` пакетный запуск снова идёт **одним** `orcai predict` по таблице (модель один раз); подмножество строк — через временный CSV + `recording_names`. В консоли job — строки `[predict-file] i/n stem`. Без таблицы — по-прежнему N×WAV.

**Статус:** Закрыт.

---

### BUG-PRED-002 — «Отменить оставшиеся» не останавливает текущий job

**Шаги:** Запустить пакетное распознавание на 5 файлах → во время 2-го файла нажать «Отменить оставшиеся».

**Факт:** Текущий `predict` job в sidecar **продолжает выполняться**; отменяются только ещё не начатые файлы.

**Ожидание:** Явное сообщение «текущий файл будет допознан» или вызов `POST /v1/jobs/{id}/cancel`.

**Файл:** `PredictPage.tsx` (`batchCancelRef`).

---

## Medium

### BUG-PRED-003 — Expert-режим не запускает распознавание

**Шаги:** Раскрыть «Расширенный режим», выбрать WAV/CSV.

**Факт:** Поле пути только для просмотра/выбора; **нет кнопки запуска** и не добавляет файл в очередь.

**Ожидание:** «Добавить в очередь» или «Распознать этот файл».

**Файл:** `PredictPage.tsx` (блок `<details expertMode>`).

---

### BUG-PRED-004 — Повторное применение `location.state` может дублировать файлы

**Шаги:** Переход на `/predict` с `state.wavPath` при уже существующей очереди без этого пути.

**Факт:** `useEffect` по `location.state` **добавляет** файл в очередь без дедупликации по `name` (только по `path` в одной ветке).

**Риск:** Дубликаты строк при навигации из «Результаты» + «Проекты».

**Файл:** `PredictPage.tsx` (~строки 118–150).

---

### BUG-PRED-005 — Очередь не синхронизируется при удалении WAV в проекте

**Шаги:** Выбрать файлы → открыть Распознавание → вернуться в проект → удалить WAV из диска/проекта.

**Факт:** `predictQueue` в localStorage **не обновляется**; в таблице остаются «мёртвые» пути.

**Ожидание:** При возврате на predict — refresh или предупреждение.

---

### BUG-PRED-006 — Сравнительные метки (`compareLabelPath`) общие для всех файлов

**Шаги:** Переключить активный файл A → B.

**Факт:** `compareLabelPath` хранится в workspace глобально, **не per-file**.

**Ожидание:** Для сверки двух прогонов на разных WAV — отдельные compare на файл.

**Файл:** `PredictPage.tsx`, `PredictSpectrogramPanel.tsx`.

---

### BUG-PRED-007 — Фильтр недоступен, если `labelPath` не записан в объект очереди

**Шаги:** Распознавание завершилось, но обновление очереди не успело / сбой записи `labelPath`.

**Факт:** Кнопка фильтра disabled при `!active?.labelPath`, хотя файл `*_predicted.txt` может существовать на диске.

**Ожидение:** Fallback: искать predicted по шаблону имени рядом с WAV.

## Low

### BUG-PRED-008 — Нет индикации «активный» файл при пакетном predict другого файла

**Факт:** Пользователь может смотреть спектрограмму файла A, пока распознаётся B — статус в таблице обновляется, но **нет предупреждения**, что активный файл не тот, что «running».

---

### BUG-PRED-009 — `outputPath` зафиксирован на `default`

**Факт:** Поле вывода из старой формы убрано; всегда `default`. Для expert-сценариев с кастомным путём — нет UI.

---

### BUG-PRED-010 — Пункт «Спектрограмма» скрыт из меню, маршрут остаётся

**Факт:** `visibleNav()` фильтрует spectrogram; `/spectrogram` → redirect. Закладки/старые материалы OK.

**Проверить:** i18n в help/docs, если упоминается отдельный раздел.

---

### BUG-PRED-011 — Home: ссылка «Распознавание» без очереди

**Факт:** С главной `Link to="/predict"` без `predictQueue` — пустая страница с текстом «выберите в проекте». Ожидаемо, но можно добавить deep-link к активному проекту.

## Рекомендуемый smoke-тест (ручной)

1. Проект с 2+ WAV → выделить 2 → «Распознавание аудиофайлов».
2. Проверить таблицу сверху, клик по строкам — смена спектрограммы.
3. «Начать распознавание» — статусы pending → running → done.
4. Метки на спектрограмме после done.
5. «Запустить фильтр» — `_filtered.txt`, статус «отфильтровано».
6. `/spectrogram` из закладки — редирект на predict.
7. «Результаты» → спектрограмма — открывается predict с файлом.

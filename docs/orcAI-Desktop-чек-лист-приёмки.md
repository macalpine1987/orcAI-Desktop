## Как отмечать

- **Pass** — критерий выполнен на реальных данных; есть доказательство (скрин, путь к файлу, строка команды).
- **Fail** — не выполнено или расходится с orcAI 3.0.2 / ТЗ.
- **N/A** — только с пояснением (например, К-13 на macOS до появления Linux-сборки).

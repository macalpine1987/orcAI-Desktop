# Этапы продолжения разработки в Cursor (ЭК-0…ЭК-3a…ЭК-18)

Каждый этап — один раздел (или сквозной слой). В сеансе: **П-n → реализация → Т-n → отчёт**.

**ЭК-1 (Clean Code) и ЭК-2 (подготовка к портам)** выполняются сразу после sidecar и действуют на все последующие этапы.

**ЭК-3a (Настройки · фундамент)** — сразу после консоли, **до** predict: i18n, DPI, persist. Полные «Настройки» (m17, пути) — **ЭК-10** в версии 0.4.

Полное ТЗ: `orcAI-Desktop-TZ-dorozhnaya-karta.pdf` (§3, §7, §11, §12).
Промты: `промты.md`. Макеты: `mockups/`.

## Правила

1. Движок orcAI **не форкается**.  
2. Версию Desktop не бампать без просьбы; не ломать `.app`.  
3. Один ЭК за сеанс (ЭК-11, ЭК-5 — несколько PNG сразу). **ЭК-3a** — отдельный сеанс между ЭК-3 и ЭК-6.  
4. ЭК-1 и ЭК-2 проверяются на каждом этапе.  
5. Windows: **DirectML обязателен** в базовой поставке (П-18).  
6. Если решение противоречит orcAI 3.0.2 — меняется решение, не движок.

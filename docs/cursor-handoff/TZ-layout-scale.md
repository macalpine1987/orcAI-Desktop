# ТЗ · Масштабирование Lab UI (окно / fullscreen / консоль / UI Scale)

**Статус:** реализовано в исходниках v0.1.13 (не бампать версию, не ломать `.app` / AUTONOMY GATE).  
**Эталон поведения:** вкладка Распознавание · **Параметры** (`.pp-params-scroll`).  
**Дата:** 2026-09-16. **Продукт:** orcAI Desktop v0.1.13.

Цель: интерфейс не искажается при изменении размера окна (от минимума 900×600 до полного экрана), при свёрнутой и развёрнутой консоли и при UI Scale 100/125%. Красота = стабильная сетка Instrument/DAW, без сплющивания, наложений и «бесконечного» растягивания героев.

---

## 0. Контекст (что уже выяснено)

В приложении смешаны три независимых механизма:

| Слой | Факт | Проблема |
|---|---|---|
| Окно Tauri | Старт 1280×800, min 900×600, resize / F11 fullscreen | Webview заполняется (`inset: 0`) — это ок |
| UI Scale | CSS `zoom` на `.app-shell-root` (100/125%; сохранённые 150% читаются как 125%) | `rem` растёт, **`vh`/`vw` — нет** |
| Консоль (Lab dock) | Свёрнута ~38px или **фиксированные 17.5rem (~280px)**, `flex-shrink: 0` | Герои на `vh` **не знают** про док |

Оболочка (`html` → `#root` → `.app-viewport` → header + (sidebar \| main) + dock) — правильная flex-колонка. **Параметры** живут в остатке и скроллятся целиком. **Результаты** считают высоты от **всего окна** (`34vh` спектрограмма, `22vh` таблица) с жёсткими `rem`-потолками — отсюда пустота в fullscreen, давка при открытой консоли, регресс «спектрограмма на весь скролл».

## 1. Нефункциональные ограничения

- Не форкать orcAI, не бампать версию Desktop без явной просьбы.
- Runtime (`startAll` / hide-on-close / динамический порт) не трогать.
- Макеты m01–m16 — источник композиции (порядок блоков, chrome), **не** пиксельная высота на 1280×800 как единственная истина.
- После правок CSS: `npm run ui:test` (релевантные). Сборку `.app` — только по запросу.
- Не чинить «только на Results», если тот же антипаттерн есть на Главной / Проектах / Задачах / Настройках / Фильтрации.

## 2. Контракт раскладки (закон)

### 2.1 Свободная область

```
work = window − header − (page chrome: tabs/toolbar) − lab dock
```

Любой studio-экран заполняет **только `work`**. Консоль всегда `flex-shrink: 0`. Рабочая панель: `flex: 1; min-height: 0; min-width: 0`.

### 2.2 Три роли блоков

| Роль | Примеры | CSS |
|---|---|---|
| **Chrome** | header, tabs, transport, сегменты, footer кнопок, свёрнутый/развёрнутый dock | `flex: 0 0 auto` (не сжимается) |
| **Герой** | спектрограмма, сетка Параметров, таблица Задач, карта Проектов | `flex: 1 1 auto; min-height: <пол в rem>` + **потолок от контейнера**, не от `100vh` |
| **Вложенный список** | очередь WAV, detections, лог в доке | свой `overflow: auto` и мягкий `max-height` от **контейнера** |

Запрещено: `min-height` = `max-height` от `vh` на герое внутри `overflow: auto` родителя (бесконечный рост или мёртвая пустота).

### 2.3 Единицы

**Можно:** `rem`, `%`, `fr`, `flex`, **`cqh`/`cqw`** на контейнере панели (`container-type: size` на `.predict-work-panel` / `.studio-panel` / `.jobs-work-panel` и аналогах).

**Нельзя в высотах героев и таблиц экрана:** `vh`, `vw`, `svh` (они игнорируют консоль и расходятся с `zoom`).

`vh` допустим только у оверлеев/модалок («не выше экрана»), с запасом на chrome: `min(32rem, calc(100vh - 3rem))`.

### 2.4 UI Scale

Не смешивать `zoom` с `vh`. После перехода героев на `cqh`/`flex` `zoom` остаётся. Не заменять zoom на `transform: scale` (ломает hit-testing). Не менять пресеты 100/125 без запроса.

### 2.5 Один внешний скролл

На studio-вкладке: один вертикальный скролл у **хоста контента** (как `.pp-params-scroll`). Родитель панели `overflow: hidden`. Если после сжатия героя до `min-height` всё равно не влезает (док + 125% + 600px) — появляется этот скролл, **без** наложения thead на спектрограмму и без `overflow: hidden` на родителе, чьи дети не умеют сжиматься.

## 3. Эталон, который копировать

**Распознавание · Параметры** (`predict-params.css`):

- Цепочка `min-height: 0` от `.predict-studio` → `.predict-work-panel` → `.predict-panel-body`.

## 4. Работы по слоям

### 4.1 Оболочка и консоль (все разделы)

Файлы: `apps/ui/src/index.css`, `layout/AppShell.tsx`, `styles/jobs-console.css`, `components/LabDock.tsx`, `lib/labDockLayout.ts`.

1. Сохранить flex-колонку viewport; проверить `data-lab-dock` = **фактическое** состояние дока (сейчас = preference, которая же и тогл — оставить согласованным).
2. Высота развёрнутого дока: **`min(17.5rem, 38cqh окна / 38% main-column)`**, пол не ниже ~10rem, чтобы на 600px док не съедал Results. Свёрнутая полоса без изменений по смыслу (~38px).
3. Док по-прежнему `flex-shrink: 0`. Не перекрывать `main`.
4. Горизонтальный сплит инспектора уже клампится — не ломать.

### 4.2 Распознавание · Результаты (критично)

Файлы: `styles/analysis-lab.css`, `styles/predict-params.css` (хост Results), компоненты studio.

1. На `.predict-work-panel` / `.predict-results-studio` задать **container queries**.
2. Спектрограмма + «Классы»:
   - `flex: 1 1 auto`;
   - `min-height: 10rem` (или 11.5rem, согласовать с m04);
   - `max-height: min(20rem, 55cqh)` **контейнера Results**, не `34vh`;
   - **запрет** `max-height: none` + `flex: 1` внутри `overflow-y: auto` (регресс бесконечного роста).
3. Transport и сегментная полоса — только chrome (`flex-shrink: 0`), без `vh`.
4. Таблица детекций:
   - не запирать `min-height = max-height` от viewport;
   - видимое тело: `clamp(3, …, 8)` строк **или** `max-height: min(35cqh, 8 строк)`;
   - внутренний скролл tbody; thead sticky; не наезжать на спектрограмму.
5. Убрать dock-gated dual scroll (`overflow` только при `data-lab-dock=expanded`) — один режим всегда, как Параметры.
6. При нехватке места: сначала сжимается спектрограмма до пола, таблица держит 3 строки + свой скролл, затем скролл studio.

### 4.3 Распознавание · Параметры и Фильтрация

- Очередь WAV: `max-height: min(50vh, 26rem)` → контейнерные единицы (`min(26rem, 50cqh)` панели).
- Фильтрация: та же цепочка flex/`min-height: 0`, что Параметры; таблицы не фиксировать в `vh`.

### 4.4 Главная (ЭК-4)

- Сетка карточек заполняет `work`, не `100vh`.
- Recent Jobs — `flex: 1; min-height: 0; overflow: auto` внутри карточки, без выталкивания футера Runtime за док.

### 4.5 Проекты (ЭК-5)

- Studio-рамка + вкладки как Параметры.
- Модалки/wizard: `vh` только как cap оверлея (`calc(100vh - 3rem)` ок).
- Списки записей/артефактов — вложенный скролл в карточке, не страница целиком под доком.

### 4.6 Задачи (m16)

- Таблица: `flex: 1; min-height: 0; overflow: auto` (уже близко).
- Не задавать высоту таблицы через `vh`.
- При открытом доке таблица отдаёт место, шапка колонок остаётся.

### 4.7 Настройки / Справка / прочие Lab-страницы

- Проверить `overflow-auto` на `main` vs studio `overflow-hidden`.
- Превью масштаба (m28) не менять по смыслу; после фикса сверить, что подписи «эффективный холст» не врут.

### 4.8 Горизонталь

- `min-width: 0` на всех flex-детях текстовых рядов (имя файла, LCD, pills).
- Transport: горизонтальный скролл ряда кнопок, не перенос на две строки (уже в media).
- Сайдбар свёрнут/развёрнут не должен ломать центральную колонку.

## 5. Запрещённые антипаттерны (ревью)

- Герой с `flex: 1` **и** `max-height: none` внутри прокручиваемого родителя.
- Высота графика/таблицы от `vh` при наличии нижней консоли.
- `overflow-y: hidden` на предке + дети с `min-content` больше предка (наложение, обрезка thead).
- Второй «режим» раскладки только для expanded dock, если collapsed из-за этого клипает.
- «Починить» пустоту fullscreen, сняв потолок спектрограммы без `max-height` от контейнера.

## 6. Приёмка (ручная)

Матрица на **одной** машине, UI Scale 100% и 125%, док свёрнут и развёрнут:

| Окно | Где |
|---|---|
| 900×600 (минимум) | нет наложений, есть скролл studio при необходимости, спектрограмма ≥ пола |
| 1280×800 (дефолт) | как m03/m04: график и таблица в одном кадре при свёрнутом доке |
| Растянуть к ~1920×1080 | спектрограмма **растёт** до контейнерного потолка, не остаётся крошечной |
| Fullscreen | то же + нет бесконечной пустой полосы и нет бесконечного графика |
| Док открыть/закрыть | график/таблица **меняются**, страница не «прыгает» наложением |

Экраны: Главная, Проекты, Параметры, Результаты, Фильтрация, Задачи, Настройки.

Критерии Pass:

- Нет thead поверх спектрограммы.
- Нет графика на весь скролл.
- Открытие консоли не прячет transport и не обрезает Classes посередине без скролла.
- 125% + док + 800px: читаемо, один скролл, кнопки нажимаются.
- Параметры визуально не регрессируют (эталон).

Автотесты: не падают существующие `SpectrogramFileSegmentRail` / predict studio tests; при изменении классов — обновить селекторы.

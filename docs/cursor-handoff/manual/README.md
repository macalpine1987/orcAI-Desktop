# Руководство пользователя orcAI Desktop

Двуязычное руководство (RU/EN) — единый источник справки для раздела **Справка → Руководство**.

## Структура

| Каталог | Назначение |
|---------|------------|
| `ru/` | Главы на русском (язык интерфейса RU) |
| `en/` | Главы на английском (язык интерфейса EN) |
| `manifest.json` | Оглавление, якоря и привязка кнопки «Справка» на экранах |

## Правила перевода

- Переводятся заголовки, абзацы, шаги сценариев, объяснения параметров.
- **Не переводятся:** имена классов (`WHISTLE`, `BUZZ`…), имена файлов (`predicted.txt`), команды CLI (`orcai predict`…), пути, DOI, имена авторов.

## Содержание (акцент)

Главы покрывают все Lab-разделы. **Обучение** (`04-train`) — самая подробная: конвейер из 8 шагов, мастер, таблицы параметров спектрограммы/модели, hpsearch, дообучение, монитор, сниппеты/`n_batch`, советы новичкам. Опирается на поведение оригинального orcAI 3.0.2.

## Реализация в приложении (FR-11.12–11.14)

1. При старте главы грузятся из bundled `docs/manual/{locale}/` (`import.meta.glob` в UI).
2. Вкладка **Руководство** — дерево глав + подпункты Распознавания и Обучения + область чтения.
3. Кнопка **Справка** на экранах открывает ту же вкладку с якорем (см. `manifest.json` → `help_topics`).
4. Язык глав = язык интерфейса, без перезапуска.

## Сборка

Копии для handoff: `docs/cursor-handoff/manual/`. Markdown входит в UI bundle; после правок пересоберите `.app`, чтобы увидеть текст в релизе.

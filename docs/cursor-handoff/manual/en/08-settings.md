# Settings

Settings are split into two tabs: **Runtime** and **Interface**. Version information is under **Help → About**.

## Runtime

- **Compute device** — processor (CPU) or graphics card (GPU). The GPU is usually much faster, especially for training. The CPU is selected on first launch because it works on any computer.
- **Autostart** — start the runtime as soon as the app opens, without clicking **Start** on Home. Off by default.
- **Log detail** — how much information orcAI writes to job logs, from 0 (essentials only) to 3 (everything). The default suits everyday work.
- **Keep job logs** — keep the job history between app sessions.
- **Folders** — where new projects are created by default and where temporary spectrogram files and logs are stored.
- **Reset settings** — restore all app settings to their original values. Your projects and models are not affected.

## Interface

- **Language** — Russian or English. The help switches along with the interface.
- **Scale** — 100, 125 or 150%. Useful on large monitors or if the text looks small.
- **Fullscreen** — open the app in fullscreen. You can toggle it at any time with F11.
- **Console** — whether the job console is expanded when the app starts.
- **Data health warnings** — tips at the top of the window when the project is missing recordings or annotations, the recordings table is outdated, or there are too few examples for training. Off by default.
- **Spectrogram in Analysis** — if turned off, the **Analysis** tab shows only the signals table. This makes the app faster on a slower computer.
- **Long recordings** — build spectrograms of very long recordings in parts to save memory.

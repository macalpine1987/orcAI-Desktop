# Глоссарий

## Термины

| Термин | Значение |
|--------|----------|
| Аннотация | Ручная разметка записи: где и какой звук слышен. Хранится в текстовом файле меток Audacity |
| Батч | Порция обучающих примеров, которую модель обрабатывает за один шаг |
| Выборки train / val / test | Три части данных: для обучения, для контроля во время обучения и для итоговой проверки |
| Гиперпараметры | Настройки устройства нейросети: число фильтров, размер ядра, dropout и другие |
| Дообучение | Продолжение обучения готовой модели на новых данных |
| Класс | Тип звука, который распознаёт модель, например `WHISTLE` |
| Конвейер | Последовательность из восьми шагов, через которые проходят данные при обучении |
| Порог | Минимальная уверенность модели, при которой сигнал попадает в результаты |
| Синонимы меток | Соответствие между подписями в аннотациях и классами модели |
| Сниппет | Короткий фрагмент спектрограммы фиксированной длины — один обучающий пример |
| Спектрограмма | Изображение звука: по горизонтали время, по вертикали частота, яркость — громкость |
| Эпоха | Один полный цикл обучения модели |

## Разделы программы и команды orcAI

| Раздел программы | Команда orcAI | Файлы |
|------------------|---------------|-------|
| Распознавание | `predict` | `*_predicted.txt` |
| Фильтрация | `filter-predictions` | `*_predicted_filtered.txt`, `call_duration_limits.json` |
| Обучение | `train` и подготовительные шаги | `models/<имя>/` |
| Дообучение | `train` с исходной моделью | `models/<имя>/` |
| Тест модели | `test` | результаты теста в папке модели |
| Создание проекта | `init` | `*_orcai_parameter.json` |
| Таблица записей | `create-recording-table` | `recording_table.csv` |
| Синонимы меток | используются шагом `create-label-arrays` | `call_equivalences.json` |

## Классы звуков

Названия классов не переводятся, чтобы их было легко сопоставить с публикациями. В таблицах программы рядом с классом приводится его расшифровка.

| Класс | Расшифровка в программе | Звук |
|-------|-------------------------|------|
| `WHISTLE` | whistles | свисты |
| `BUZZ` | buzzing | жужжание — серии очень частых щелчков |
| `PHS` | prey handling sounds | звуки при обработке добычи |
| `SS` | pulsed calls | импульсные крики |
| `BR` | breathing | дыхание |
| `HERDING` | herding calls | звуки при загоне добычи |
| `TAILSLAP` | tail slaps | удары хвостом по воде |

Точный набор классов зависит от модели — посмотреть его можно в описании модели в разделе **Модели**.

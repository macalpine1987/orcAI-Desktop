# Модели

Здесь собраны все модели, которыми можно пользоваться: встроенные в программу и обученные в вашем проекте.

## Встроенные модели

- **`orcai-isl-v1`** — основная модель, обученная на большом наборе записей исландских косаток, которые охотятся на сельдь. Её можно использовать как есть или дообучить на данных другой популяции.
- **`orcai-nor-v1`** — модель `orcai-isl-v1`, дообученная на записях норвежских косаток.

Модели, которые вы обучите сами, хранятся в папке проекта `models/`, каждая в своей подпапке.

## Что можно сделать с моделью

Выберите модель в таблице — справа появится её описание: классы звуков, параметры спектрограммы и результаты теста, если он проводился.

- **Использовать** — сделать модель текущей для распознавания.
- **Дообучить** — открыть мастер обучения, где эта модель будет взята за основу.
- **Тест** — измерить качество модели на тестовой выборке проекта. Для этого в проекте должны быть подготовлены данные для обучения.
- **Импорт** — добавить в проект модель из другой папки, например полученную от коллег.
- **Экспорт** — скопировать модель в другую папку, чтобы передать её или сохранить копию.
- **Открыть папку** — показать файлы модели в Finder.

## Результаты теста

После теста для каждого класса показываются два показателя:

- **Точность** — какая доля найденных моделью сигналов действительно относится к этому классу. Низкая точность означает много ложных срабатываний.
- **Полнота** — какая доля настоящих сигналов этого класса найдена. Низкая полнота означает, что модель многое пропускает.

## Совместимость

Модель можно применять только к данным, подготовленным так же, как те, на которых она обучалась: с теми же классами звуков и теми же параметрами спектрограммы. Программа проверяет это автоматически и не даст выбрать несовместимую модель без предупреждения.

# Настройки

Настройки разделены на две вкладки: **Среда выполнения** и **Интерфейс**. Сведения о версии программы находятся в разделе **Справка → О программе**.

## Среда выполнения

- **Устройство вычислений** — процессор (CPU) или видеокарта (GPU). Видеокарта обычно работает заметно быстрее, особенно при обучении. При первом запуске выбран процессор, потому что он работает на любом компьютере.
- **Автозапуск** — включать среду выполнения сразу при открытии программы, без нажатия **Запуск** на Главной. По умолчанию выключен.
- **Подробность журнала** — сколько сведений orcAI записывает в журнал задач: от 0 (только самое важное) до 3 (всё). Для обычной работы подходит значение по умолчанию.
- **Сохранять журналы задач** — хранить историю задач между запусками программы.
- **Папки** — где по умолчанию создавать проекты, хранить временные файлы спектрограмм и журналы.
- **Сброс настроек** — вернуть все настройки программы к исходным. Ваши проекты и модели при этом не затрагиваются.

## Интерфейс

- **Язык** — русский или английский. Справка переключается вместе с интерфейсом.
- **Масштаб** — 100, 125 или 150 %. Удобно на больших мониторах или если текст кажется мелким.
- **Полноэкранный режим** — открывать программу во весь экран. Переключить режим в любой момент можно клавишей F11.
- **Консоль** — показывать ли консоль задач развёрнутой при запуске.
- **Предупреждения о данных** — подсказки в верхней части окна, если в проекте не хватает записей или аннотаций, устарела таблица записей или для обучения недостаточно примеров. По умолчанию выключены.
- **Спектрограмма в анализе** — если выключить, на вкладке **Анализ** останется только таблица сигналов. Это ускоряет работу со слабым компьютером.
- **Длинные записи** — строить спектрограмму очень длинных записей по частям, чтобы не расходовать много памяти.

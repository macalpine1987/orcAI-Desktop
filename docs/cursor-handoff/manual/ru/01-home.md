# Главная

Главная — стартовый экран программы. Здесь включаются вычислительные компоненты, видно состояние текущего проекта и есть быстрые переходы к основным задачам.

## Среда выполнения

Прежде чем распознавать записи или обучать модели, нужно включить две части программы:

- **Sidecar (API)** — внутренняя служба, через которую интерфейс передаёт команды orcAI. Она работает только на вашем компьютере и в интернет не выходит.
- **Движок orcAI** — нейросеть, которая выполняет вычисления на процессоре (CPU) или видеокарте (GPU).

Кнопки блока:

- **Запуск** — включает обе части.
- **Перезапустить** — полностью выключает и снова включает их. Помогает, если что-то перестало отвечать.
- **Остановить** — выключает вычисления и освобождает память. Окно программы при этом остаётся открытым.

Когда всё готово, лампы горят зелёным.

На macOS кнопка закрытия окна (или ⌘W) только прячет программу: начатые вычисления продолжаются в фоне. Чтобы полностью выйти, нажмите ⌘Q.

Выбор между CPU и GPU находится в **Настройках**. После смены устройства движок перезапускается сам.

## Текущий проект

Карточка показывает, что есть в открытом проекте: сколько записей и аннотаций, для скольких записей уже есть результаты распознавания, какая модель выбрана. Кнопки **Открыть папку** и **Сменить** ничего не меняют в файлах — они только открывают папку в Finder или переключают проект.

## Предупреждения о данных

Программа может подсказывать, если с данными проекта что-то не так: не хватает записей или аннотаций, таблица записей устарела или для обучения недостаточно примеров. Подсказки появляются в верхней части окна и ничего не запрещают.

По умолчанию они выключены. Включить их можно в **Настройки → Интерфейс → Предупреждения о данных**.

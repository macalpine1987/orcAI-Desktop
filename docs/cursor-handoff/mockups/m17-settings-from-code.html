Запускать движок при старте

Иначе — вручную кнопкой на «Главной».

Длинные записи

Для записей длиннее 20 минут спектрограмма строится только на видимом участке — так быстрее листать длинные файлы. Результаты распознавания не меняются.

Закрытие окна

Движок продолжает работу в фоне. macOS: крестик и ⌘W скрывают окно; ⌘Q — полный выход.

Устройство для нейросети

По умолчанию CPU. Где TensorFlow выполняет распознавание и обучение. После смены среда перезапускается.

При смене CPU/GPU среда для анализа перезапускается автоматически.

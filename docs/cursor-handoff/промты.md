# orcAI Desktop — промты реализации и тестирования

Двадцать пар заданий: **П-n** (реализация) + **Т-n** (тест); **П-13a** — сквозной фундамент настроек до predict. Порядок работ в Cursor — **§12 ТЗ (ЭК-0…ЭК-3a…ЭК-18)**: после sidecar — **П-19** и **П-15**; сразу после консоли — **П-13a (ЭК-3a)**; полные «Настройки» — в **0.4** вместе со «Справкой»; порты — в конце ветки.

Как пользоваться: общий контекст → П-n + PNG-макет(ы) → реализация → Т-n (только проверка, без дописывания функций). Макеты: `docs/ui-memory/tz2-mockups/` (**m01–m38**, d01–d02, всего 40 PNG; см. INDEX.md). Руководство: `docs/manual/`.

Полное обоснование — в `orcAI-Desktop-TZ-dorozhnaya-karta.pdf` (§3, §7, §8, §11).

## Общий контекст

```
Контекст проекта (не менять без явного указания):
· Workspace: /Users/vadimromanov/.cursor/projects/empty-window/orcai-desktop
· orcAI Desktop — Tauri 2 + React/TypeScript + Python-sidecar (FastAPI, runner.py) + встроенная orcAI 3.0.2.
· Движок не форкается. Любая предметная логика — вызов команды orcAI, а не собственная реализация.

· Языки RU и EN. В RU predict называется «Распознавание» (не «предсказание» в UI; «предсказание» — только для имён файлов *_predicted.txt). Имена файлов, классов и параметров не переводятся.
· Sidecar и движок стартуют вручную, порт динамический. Закрытие окна скрывает приложение.
· Версия кода 0.1.8. Подпись v0.2.x на макетах — целевой chrome ТЗ; версию не бампать, сборку .app не ломать.
· Значения по умолчанию берутся из orcAI, а не задаются в приложении заново.
· Окно: обычный и полноэкранный режим; UI следует разрешению и системному DPI (мин. комфортно 1280×800; проверить также 1920×1080 и масштаб 125/150 %).
· Python (sidecar и модули приложения): Clean Code + PEP 8 с первого коммита (ЭК-1 / П-19); проверка ruff/flake8. Код внутри бандла orcAI не рефакторить.
· Кросс-платформа: пути через API оболочки, case-sensitive имена, абстракция ускорителя (ЭК-2 / П-15) — до портов Linux/Windows.
· Макеты: docs/ui-memory/tz2-mockups/ и docs/cursor-handoff/mockups/.
· Обоснование: docs/cursor-handoff/orcAI-Desktop-TZ-dorozhnaya-karta.pdf (или /tmp/…), разделы 3, 7, 8, 11 и 12.
```

> Если решение противоречит orcAI 3.0.2 — меняется решение, а не движок.

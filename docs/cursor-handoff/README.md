# orcAI Desktop — пакет для продолжения в Cursor

Готовый контекст для агента: этапы по разделам UI, промты реализации и тестирования, макеты, полное ТЗ.

## Состав

| Файл / папка | Назначение |
|--------------|------------|
| `START_HERE.md` | Шаблон первого сообщения в Cursor |
| `этапы.md` | ЭК-0…ЭК-3a…ЭК-18: раздел → промт → макет |
| `промты.md` | 20 пар П-n / Т-n (включая П-13a) |
| `чек-лист-приёмки.md` | Копия ручной приёмки (источник: `docs/orcAI-Desktop-чек-лист-приёмки.md`) |
| `mockups/` | PNG m01–m38, d01–d02 (40 файлов) |
| `manual/` | Руководство RU/EN (docs/manual/) + manifest.json |
| `orcAI-Desktop-TZ-dorozhnaya-karta.pdf` | Полное техническое задание |
| `TZ-layout-scale.md` | Масштабирование Lab UI (окно / fullscreen / консоль / UI Scale) |

Копия этого пакета в репозитории: `docs/cursor-handoff/`.  
Временная копия: `/tmp/orcAI-Desktop-Cursor-пакет/`.

## Быстрый старт

1. Открой workspace `orcai-desktop` в Cursor.  
2. Новый Agent-чат → вставь `START_HERE.md`, укажи **ЭК-N**.  
3. Приложи соответствующий PNG из `mockups/`.  
4. После «Готово, когда» — вставь парный **Т-n** из `промты.md`.
